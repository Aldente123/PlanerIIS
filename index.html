Какая ставка НДФЛ у вас по основному виду дохода?

Она нужна для расчёта вычета на внесённые деньги. Для инвестиционного дохода действует отдельный порядок налогообложения.

ВажноЭта ставка применяется только к доходам, с которых удержан подходящий для вычета НДФЛ.
  • Если подходящего НДФЛ нет — выберите 0%. Вычет на взнос не будет учтён.
  • При наличии подходящего НДФЛ база для вычета — до 400 000 ₽ взносов в год.
